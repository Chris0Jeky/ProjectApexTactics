# Project Apex Tactics

Project Apex Tactics is a prototype Unity project, not a production application.

## Open the project

Use Unity Hub to open this repository with **Unity 6000.0.46f1**. The exact editor version is recorded in `ProjectSettings/ProjectVersion.txt`.

## Current contents

The repository currently contains Unity project settings, package configuration, input actions, Universal Render Pipeline settings, asset-folder structure, and two tracked scenes: `Assets/Scenes/SampleScene.unity` and `Assets/Settings/Scenes/URP2DSceneTemplate.unity`.

No C# source files or authored gameplay implementation are tracked. There is no public build or release.

Unity `.meta` files are intentionally tracked so Unity asset references and GUIDs remain stable across checkouts.
